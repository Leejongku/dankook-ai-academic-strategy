## 📌 개요

학사정보시스템에 AI를 접목하여 학생이 직접 체감하는 편의 서비스를 단계적으로 구현하기 위한 전략 기획 문서입니다.

- **대상:** 단국대학교 재학생 (웹 정보시스템 + 모바일 앱 접점)
- **범위:** 학적·수업·성적·학사일정·장학·등록·졸업·진로 8개 메뉴
- **AI 범주:** 7가지 (예측·추천·NLP·경보·자동화·개인화·의사결정 지원)

## 🚀 3단계 도입 로드맵

```
1단계 (0~6개월)    학사·강의 AI 챗봇, 강의계획서 요약, 성적 비율 분석
                   학사일정 AI 체크, 등록금 안내 → NLP · 자동화 · 경보

2단계 (6~12개월)   성적 추이 분석, 졸업요건 체커, 장학금 추천
                   출석 위험 감지, 학습 플래너 → 예측 · 추천 · 개인화

3단계 (12개월~)    AI 진로 로드맵, 글쓰기 보조, CQI 피드백 AI
                   졸업 예측 시뮬레이션 → 의사결정 · NLP · 추천
```

## 🤖 AI 7가지 범주

| 범주 | 설명 | 주요 적용 |
|------|------|-----------|
| **예측** | 과거 데이터로 미래 상태 추정 | 성적 예측, 졸업 시점, 학업 위험군 |
| **추천** | 개인 맥락 기반 최적 선택지 제시 | 수강신청, 장학금, 진로 경로 |
| **NLP** | 텍스트 이해·생성·분류 | 챗봇, 요약, CQI 분석, 글쓰기 보조 |
| **경보** | 임계치 초과 자동 감지·알림 | 출석·성적 경보, 마감 D-day |
| **자동화** | 반복 업무 완전 자동 처리 | 캘린더 등록, 졸업요건 집계 |
| **개인화** | 개인 패턴 학습 → 맞춤 경험 | 알림 시점, 학습 플래너, 언어 조절 |
| **의사결정 지원** | 복합 데이터 분석 → 판단 근거 제공 | 학점 전략, 상담 지원, IR |

## 📡 기타 데이터소스 확장 (9가지)

1. **도서관 대출·열람** → 참고문헌 추천, 학습 집중도 분석
2. **취업·진로지원** → 선배 경로 추천, 채용 마감 경보
3. **학생상담센터** → 번아웃 위험 감지, 상담 프로그램 추천 *(비식별화 필수)*
4. **시설·공간 이용** → 스터디룸 추천, 혼잡도 예측
5. **LMS 학습 활동 로그** → 이탈 감지, 학습 유형 개인화
6. **국제교류·어학** → 교환학교 매칭, 다국어 챗봇
7. **비교과·동아리 활동** → 진로 활동 추천, 자소서 스펙 자동 정리
8. **생활·건강** → 시험 기간 식단 추천, 건강 이상 경보
9. **외부 공개 데이터** → 채용 공고 매칭, 국가장학금 알림

## 🔧 기술 스택

- **DB:** Oracle (기존 학사 DB)
- **AI API:** OpenAI GPT-4o / Anthropic Claude (프록시 방식)
- **Frontend:** X-Platform (UX Studio V9.2) + 스마트캠퍼스 앱
- **Backend:** Java + REST API 게이트웨이
- **개인정보:** 비식별화 처리 + 학생 동의 관리 시스템
